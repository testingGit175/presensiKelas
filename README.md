
# Aplikasi Presensi Kelas XI RPL

## Deskripsi
Aplikasi Presensi Kelas XI RPL merupakan aplikasi berbasis Flutter yang digunakan untuk membantu proses pencatatan dan pengelolaan kehadiran siswa di kelas.

## Fitur Aplikasi
- Menampilkan daftar siswa.
- Menandai siswa yang hadir.
- Menghitung jumlah siswa yang hadir.
- Menghitung jumlah siswa yang tidak hadir.
- Menampilkan rekap presensi.
- Menghitung persentase kehadiran siswa.

## Teknologi yang Digunakan
- Flutter
- Dart
- JSON
- GitHub

## Struktur Project
- `lib/` : Menyimpan source code aplikasi.
- `assets/` : Menyimpan data siswa.
- `android/` : Konfigurasi aplikasi Android.
- `test/` : Menyimpan file pengujian.
- `pubspec.yaml` : Konfigurasi project Flutter.

## Cara Menjalankan Aplikasi

1. Clone repository.
2. Buka folder project di VS Code.
3. Jalankan perintah:

   flutter pub get

4. Jalankan aplikasi:

   flutter run

## Build APK

Gunakan perintah:

flutter build apk --release
